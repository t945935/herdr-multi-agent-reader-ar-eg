# حزمة التطبيقات العملية لقراء Herdr Multi-Agent

إصدار الموارد: `1.0.0` — الإصدار المقابل من الكتاب: `1.0` — اللغة: العربية الموجّهة إلى قراء مصر، `ar-EG`.

تضم هذه الحزمة البرامج القابلة للتنفيذ والاختبارات وموجّهات الأدوار والتعليمات المختصرة المرافقة لكتاب **سير عمل موثوقة متعددة الوكلاء باستخدام Herdr — الطبعة المصرية**. ولا تتضمن نص الكتاب المدفوع.

تُنشر الحزمة بإذن خاص بترجمة موارد هذه الطبعة إلى العربية وتوزيعها. وهي مخصصة لمرافقة قراءة الكتاب وتشغيل أمثلته. لا يوجد ترخيص عام مفتوح المصدر؛ وإتاحة التنزيل العام لا تمنح إذنًا أوسع بإعادة التوزيع أو الاستخدام التجاري. للاستفسار عن استخدام آخر، اتصل بالقائم على الصيانة عبر [GitHub Issues](https://github.com/t945935/herdr-multi-agent-reader-ar-eg/issues).

## التثبيت والاختبار

استخدم Python 3.12 من جذر الحزمة بعد فك ضغطها:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pytest -q tests
```

النتيجة المرجعية المتوقعة: `42 passed`. يختبر ذلك الحساب والدرجات وعقد HTTP والتسليم وأدلة البحث ومسارات فشل خط التنفيذ وتزامن طابور العمل واستعادته. لا تتطلب الأمثلة المرجعية حساب نموذج؛ أما إسناد العمل الفعلي فيتطلب إعداد Herdr وواجهة CLI وتسجيل الدخول إليها.

راجع [`examples/README.md`](examples/README.md) لمعرفة مواءمة الفصول وتشغيل الموقع وإرشادات التمارين. ويسجّل [`CHANGELOG.md`](CHANGELOG.md) تاريخ إصدارات الحزمة.

```bash
sha256sum -c SHA256SUMS.txt
```

عند التطابق يظهر اسم الملف متبوعًا بـ `OK`. فكّ الضغط في مجلد قابل للكتابة ونفّذ أوامر التثبيت من الجذر الذي يحتوي على `examples/` و`tests/`. يحتوي `resource-manifest.json` على قيم التجزئة لكل ملف.
