# Backend

عدّل `examples/task_manager/main.py` فقط. هيّئ الجداول عبر FastAPI `lifespan`، وارفض الحقول غير المعروفة والتحويل الضمني للأنواع. نجاح POST هو 201، وPATCH هو 200، وDELETE هو 204؛ والبيانات غير الموجودة تعيد 404، والمدخلات غير الصالحة تعيد 422. تبقى قيم حقول PATCH المحذوفة كما هي؛ وتُرفض قيمة `null` الصريحة؛ ويمكن مسح `description`. لا تعدّل الملفات المملوكة لدور Database.
