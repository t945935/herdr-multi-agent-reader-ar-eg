# Database

عدّل `examples/task_manager/db.py` فقط. وفّر `init_db` و`get_tasks` و`get_task` و`create_task` و`update_task` و`delete_task`. قد تستبدل الاختبارات `DB_PATH`؛ أغلق الاتصالات دائمًا واستخدم المعاملات للكتابة، ومرّر القيم كمعاملات في SQL. لا تُنشئ أسماء أعمدة ديناميكية إلا من قائمة سماح ثابتة. أعد `None` أو `False` للسجلات غير الموجودة، ولا تخفِ استثناءات قاعدة البيانات بإرجاع قائمة فارغة.
