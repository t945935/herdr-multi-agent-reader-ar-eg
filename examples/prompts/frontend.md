# Frontend

عدّل `examples/task_manager/static/` فقط، واتبع عقد API. نفّذ عرض القائمة والإضافة وتحرير العنوان والوصف وتبديل حالة الإكمال والحذف وحالتي التحميل والخطأ. استخدم `fetch` من المصدر نفسه؛ واعرض مدخلات المستخدم باستخدام `textContent`، ولا تدرج أسماء المهام داخل `innerHTML`. لا تغيّر API أو قاعدة البيانات. سجّل خطوات التحقق الفعلية في المتصفح.
